Corrections from v2 — all verified against code:
  • AddressCollectionScreen is NOT in checkout. Payment runs entirely inside CartScreen (lines 538-770) → PhonePe → orderAck. AddressCollectionScreen is the post-login address picker (WelcomeScreen.tsx:49) and no-location fallback (LandingScreen.tsx:333).
  • Subscription self-serve is dormant today. reduxIsSelfSubscriptionEnabled defaults to false (appConfigTempReducer.ts:18); set from json.isSelfSubscriptionEnabled on /home_v3/get_landing_page_data (LandingScreen.tsx:226). When false, SubscriptionScreen.tsx:842-850 silently redirects to subscriptionRequestScreen → form submit (POST /contact_us/subscription_contact). No payment.
  • Get Today / Get Later / Subscribe are parallel modes. User picks ONE from main. Get Today + Get Later converge at ChefFoodListScreen → CartScreen → Payment → orderAck. Subscribe today exits via form submission with no convergence.
  • Search is supplementary, not a journey lane. Always-on widget on Landing/Home/GetNow.
  • FestiveDishDetailScreen is a contact form, not a purchase. POST /contact_us/save_festival_request.
  • Step8Checkout in SubscriptionScreen is dead code. No setCurrentStep(8) anywhere — UI mockup with Alert.alert("Payment Simulated").
