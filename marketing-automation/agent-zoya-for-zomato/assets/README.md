onboarding. Shows the chef block, rates, a priced item, a held-back item, the market block that
feeds the chef sheet's rationale, a rate change, and an open question. Copy it as a starting
shape rather than writing the file from scratch.

Field-by-field notes are in `references/data-contract.md`.
