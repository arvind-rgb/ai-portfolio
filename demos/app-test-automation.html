App Test Automation

An AI QA pipeline for a React Native app

Three chained Claude Code skills take a 33-screen Expo/React Native app from zero tests to a human-reviewed 191-case catalog, compiled into Maestro flows and run on an Android + iOS matrix in GitHub Actions.

  • Claude scans the codebase into screen and journey maps, with every claim cited to file:line
  • Generates prioritised test cases (P0–P3, smoke, functional, negative, edge)
  • Editable review dashboard: approve, reject, comment, coverage matrix, run results, bugs
  • Compiles approved cases into Maestro flows and runs them on a free device matrix in CI
